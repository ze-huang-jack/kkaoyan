# 零、一些理解
### 存储器的分类
- 按存储元件
	- 靠电荷或电压：半导体存储器：DRAM、SRAM
	- 靠磁化方向：硬盘、磁带
	- 靠光介质反射率：光盘
- 按存取方式
	- 随机存取方式：RAM
	- 顺序存取：磁带、SAM
	- 直接存取：兼具随机存取和顺序存取，机械磁盘、DAM
	- 相联存取：按内容而非地址存取，快表、路由表
- 按信息的可更改性
	- 只读存储器：ROM
	- 可读可写存储器: RAM
- 按信息的可保存性
	- 断电后信息丢失，RAM
	- 断电后信息保持，ROM、磁盘、闪存

### 主存的组成和基本操作
主存是由4部分组成:
- 存储体
- 地址寄存器(MAR, Memory Address Register)
	- CPU通过MAR发地址
	- 保存CPU当前要访问的内存地址
	- MAR的位数等于地址线位数
		- 地址线位数决定最大可寻址范围
		- 例如：36位地址的可寻址范围为0~$2^{36} - 1$ 
- 数据寄存器(MDR, Memory Data Register)
	- CPU通过MDR收发数据
	- 保存CPU与主存之间传送的数据
	- MDR的位数等于数据线宽度
		- 例如：数据线64位，那么字节编址下，每次可以并行存取64/8=8个字节
- 读写控制电路
	- 决定读还是写

### 存储器的主要性能指标
- 存取时间
	- 完成一次读/写操作所需的时间
		- 读出时间是从主存接收到有效地址到数据有效输出的时间
		- 写入时间是从主存接收到有效地址到数据成功写入指定单元的时间
- 存储周期
	- 存储器进行连续两次独立的读/写操作所需的最小时间间隔
	- 通常，存储周期大于存取时间，因为每次存取完后，还需要一定的复原时间
- 存储器带宽
	- 存储器每秒能传输的最大数据量
	- 例如存储周期位50ns，每个周期可传输64位数据，那么理论带宽为64bit / 50ns =1.28Gb/s



## 存取周期(Memory Cycle)
存取周期：存储器连续启动两次**独立**读写操作所需的最小时间间隔。

- 场景 A：DRAM 刷新：一次行选，内部自动读 + 写回 → **1 个存取周期**
- 场景 B：CPU 发读命令，CPU 再发写命令 → **2 个存取周期**
- 场景 C：CPU 读 → CPU 写 → CPU 再读 → **3 个存取周期**

## (四) DRAM的特点
![[Pasted image 20260928191104.png]]
选C，我错选了A

DRAM 只要不读、不写，我们存的数据本身不应该变

DRAM采用电容保存电荷来表示0和1：有电荷表示1，无电荷表示0。电容容易漏电，电荷会慢慢跑调，信息就丢失了，所以需要定期刷新
所谓刷新，把DRAM里每一行的数据读出来，再原样写回去，给电容补电荷，即给电容充电
所以一个完整的刷新过程，即芯片内部读出+写入，访存一次（CPU只发起了一次请求行地址触发一次刷新操作），占用一个存取周期

刷新只是读出该行原有数据，再原样写回去补电容电荷，**不会改变存储的 0/1 信息**

访存，是CPU向主存发起一次独立的读/写命令。注意是CPU发起

几次独立访存，就对应几个存取周期
