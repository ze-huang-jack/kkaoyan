## 2. 主存储器
①主存是由 RAM 和 ROM 组成的。其中 RAM 一般是 DRAM，而 cache 主要用 SRAM
SRAM 和 DRAM 的区别是：SRAM的原理是通过晶体管，不需要再生；而 DRAM 的原理是通过电容器上的电荷来表示 0 和 1，电荷容易流失，所以需要经常再生。

②DRAM 芯片**地址引脚**复用技术：地址引脚只需要原来的一半

③多模块存储器：四体交叉

## 5. cache

①分析代码的时空局部性。时间局部性就是一个内存位置被反复访问。空间局部性是一个内存位置被访问，它旁边的内存位置很快就会被访问。

②cache数据一致性问题
cache 写命中的意思是 CPU 要修改的主存地址对应的数据块已经在 cache 里面了
比如 `M[100]=20`, cpu 要修改主存为 100 的数据为 20，如果 100 所在的内存块已经在 cache 了就叫 cache 写命中
cache 写命中的处理方法
1. 直写法，每次写命中读一次内存，同时修改 cache 和内存里的内容
2. **回写法**，写命中时，只修改 cache 的数据（设置脏位=1），先不立即修改主存，仅在该脏块被替换出 cache 时修改主存 
cache 写不命中的处理方法
3. 写分配法，当写不命中时，修改主存，写入 cache
4. 非写分配法，当写不命中时，只修改主存，不写入 cache

③cache中主存块替换算法：随机、FIFO(先进先出）, LRU(Least Recently Used), LFU(最不经常使用，Least Frequently Used)

④cache和主存的映射方式：1. 直接映射 2. 全相联映射 3. 组相联映射

## 2. IO 方式
三种方式：程序询问、中断驱动方式、DMA方式

①中断处理过程的九个步骤（中断嵌套）或 7 个步骤（单重中断）


②中断屏蔽寄存器：1表示把这个中断源给屏蔽了，所有中断源都屏蔽自身（不然就会无限递归循环)
0 表示让这个中断通过，意思是这个中断源比现在执行的中断的优先级要高

假如四位中断屏蔽寄存器：
ABCD
1111：表示最高优先级，没有任何中断
1011: 表示 B 可以打断这个中断


易错点：
③外部设备只能请求可屏蔽中断，所以只要响应外部设备的中断请求，说明当前一定处于开中断状态。换句话说，只有处于开中断，CPU才能响应外部设备的中断。
注意这里是外部设备，一般来讲，CPU处于关中断时，也可以响应不可屏蔽中断


④CPU 只能在 指令执行完后检测中断请求，一旦检测到，就响应
