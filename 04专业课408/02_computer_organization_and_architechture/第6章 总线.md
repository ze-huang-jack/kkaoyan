## (七) 总线单向或双向
![[Pasted image 20260928103520.png]]
选B，我错选了C

控制信息是CPU发给主存/外设的，比如读写信号
状态信息是外设发给CPU的信号，比如就绪、中断请求

控制总线是双向的，但是控制信息只能单向传输，回来的那个信号叫状态信息，走的是另外的信号线，信息种类不同

| 信息类型     | 传输方向 | 流向            |
| -------- | ---- | ------------- |
| 地址信息     | 单向   | CPU → 主存 / 外设 |
| 数据信息     | 双向   | CPU ↔ 主存 / 外设 |
| 控制信息（命令） | 单向   | CPU → 主存 / 外设 |
| 状态信息（应答） | 单向   | 主存 / 外设 → CPU |

## (十六) 不支持突发传送计算总线事务时间
![[Pasted image 20260928113259.png]]
选D

地址传送+设备响应（数据准备）+数据传送，分别需要1ns、6ns、1ns，共8ns
总线一次传8B，总32B，需要传4次，所以4 × 8ns = 32ns

如果支持突发传输，那么总时间是 1ns + 6ns + 1ns × 4 = 11 ns
突发传输的总线事务时间 = 一次地址传送 + 一次数据准备 + 多次数据传送
