# 寻址方式
零地址寻址：这个寻址方式的指令没有地址码，操作数是隐含的。

立刻数寻址：数据本身就是操作数
直接寻址：指令里 A 是有效地址
间接寻址：指令里的 A 是形式地址，M\[A] 是有效地址

寄存器类：
寄存器寻址：寄存器里存的是操作数 
寄存器间接寻址：寄存器里存的是有效地址

偏移类：
相对寻址：EA=(PC) + A
基址寻址：EA =  (BR) + A，基址寄存器存的是程序的初始地址，不怎么变化；A里面存的是偏移量，一般经常变化
变址寻址：EA = （IX) + A，变址寄存器存的是程序的偏移量，经常变化；A里面存的是程序的初始地址，不怎么变化

# RISC 和 CISC 的区别
精简指令集计算机：
指令等长且规整
使用 load/store 指令
硬布线控制
指令比较简单


复杂指令集计算机：
指令一般不等长
不采用 load/store 指令
微程序控制
指令较为复杂，一条指令可以做很多事
