##### 链接组织方式
优点：
- 消除外部碎片
- 容易插入、删除和修改记录
- 能适应文件的动态增长

1. 隐式链接组织方式、
只适用于顺序访问
2. 显式链接组织方式
把用于链接文件各物理盘块的指针，显式地存放在内存的一张链接表中

##### 索引组织方式
支持直接访问
没有外部碎片



# 要点

unix操作系统中，I/O设备视为特殊文件

在访问文件时，需要根据文件名对目录文件进行检索。其检索性能主要与目录项数量、目录项的大小、目录项在目录中的位置有关，跟文件大小没什么关系。
%%
找文件和读文件是两个不同的过程。
找文件，找的是目录；读文件，读的是文件内容
*读文件的时候，记得要多访问一次磁盘*
%%

对于在一堆盘块里中目录项/FCB的时候，顺序查找的话：查找磁盘的次数=（查找长度+1）/2；
的话是查找长度的平方根

索引节点（inode)分两种：磁盘索引节点和内存索引节点
目录项=文件名 + 索引节点指针/编号，比如14B的文件名+2B的索引节点编号，这显著地降低了磁盘启动次数
索引节点是对传统FCB的一次增强升级，UNIX采用文件名和文件描述信息的分离的策略，文件描述信息全在索引节点里记录着

###### 文件的逻辑结构和物理结构
文件的逻辑结构分为无结构文件（流文件）和有结构文件（记录文件），有结构文件又可以按文件的组织方式分为：1. 顺序文件 2. 索引文件（涉及索引表） 3. 索引顺序文件

而文件的物理结构直接由文件的分配方式（外存组织方式）决定，有：连续组织方式、链接组织方式、索引组织方式（索引表/索引块）
或者：连续分配、链式分配（分为隐式链接方式和显式连接方式）、索引分配

那么显式链接方式涉及到FAT(File Allocation Table), OS可以直接用FAT来管理磁盘的空闲空间

这里经常会涉及到的是链式分配不适合随机访问，而连续分配和索引分配都有高效率的随机分配

而不利于文件动态增长的是连续分配，因为它会覆盖末尾的文件内容
连续分配比较容易产生外部碎片
采用连续分配方式时，目录项里的文件物理地址字段记录文件的第一块盘号编号和文件长度（多少个盘块）
连续分配在增加一块盘块时是io磁盘操作最多的，因为整个文件可能都要搬家
连续分配顺序访问是最快的

文件的分配方式是分配非空闲磁盘的方面
文件的存储空间管理涉及分配空闲磁盘，有：空闲表法、空闲链表法(空闲盘块链和空闲盘区链）、位示图法、成组链接法

-
对于算单个**文件最大长度**的题目直接用磁盘块大小除以地址项大小得到，一个索引块能指向多少个数据块N，接着，看索引节点的组成：比如7个地址项：4个直接地址索引、2个一级间接地址索引和一个二级间接地址索引，那么4 x 数据块大小 + 2 x N x 数据块大小 + 1 x N^2 x 数据块大小 = （直接索引的个数 + 一级索引的个数 x N + 二级索引的个数 x N^2) x 数据块大小

已经索引块(盘块)大小和地址项, 两者相除，得一个索引块能指向多少个数据块(也是索引块或盘块)

-文件共享
对于算引用计数的题目，硬链接+1，软链接不管，每个文件本身有1个引用计数
硬链接本质是多个目录项指向同一个inode；软链接是讲共享的文件的路径保存下来

|对比项|连续分配（Contiguous）|链接分配（Linked）|索引分配（Indexed）|
|---|---|---|---|
|文件目录（FCB/inode）记录什么？|**起始盘块号 + 文件长度（盘块数）**|**起始盘块号（有时还记录尾盘块）**|**索引块号（或inode中的直接/间接地址）**|
|数据在磁盘上的样子|必须连续|可以分散|可以分散|
|找下一块的方法|当前块号+1|当前块里存着下一块地址|查索引块|
|是否需要额外索引块|❌ 不需要|❌ 不需要（指针存在数据块中）|✅ 需要索引块|
|随机访问|⭐⭐⭐⭐⭐ 很快|⭐ 很慢|⭐⭐⭐⭐ 很快|
|顺序访问|⭐⭐⭐⭐⭐|⭐⭐⭐⭐|⭐⭐⭐⭐|
|文件扩容|最困难|很容易|很容易|


| 考点       | 连续分配           | 链接分配           | 索引分配                                 |
| -------- | -------------- | -------------- | ------------------------------------ |
| 目录记录什么   | 起始块+长度         | 起始块（可加尾块）      | 索引块号                                 |
| 数据是否连续   | ✅              | ❌              | ❌                                    |
| 是否有外部碎片  | ✅ 有            | ❌              | ❌                                    |
| 是否有内部碎片  | 可能有（最后一个盘块未用满） | 可能有（最后一个盘块未用满） | 可能有（最后一个盘块未用满，索引块也可能未用满）             |
| 随机访问     | 最快             | 最慢             | 很快                                   |
| 扩容       | 最困难（可能整体搬迁）    | 最容易            | 容易                                   |
| 现代文件系统使用 | 几乎不用           | FAT采用链式思想      | **Linux ext4、NTFS 等主流文件系统都属于索引分配思想** |
