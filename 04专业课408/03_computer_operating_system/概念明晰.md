单道批处理系统
	同一时刻内存里只有一个程序
多道批处理系统
	同一时刻内存里有多个程序

|脱机 I/O|DMA|
|---|---|
|借助另一台计算机或外围设备完成 I/O|借助 DMA 控制器完成数据传输|
|目标是减少主机等待|目标是减少 CPU 参与数据搬运|
|属于操作系统发展的早期技术|属于现代计算机硬件技术|
- **脱机 I/O**：让**另一台设备**帮主机做慢速 I/O 工作。
- **DMA**：让**DMA 控制器**帮 CPU 搬运数据，不用 CPU 一个字节一个字节地复制。


### 饥饿和忙等的区别

|          | 饥饿 (Starvation) | 忙等 (Busy Waiting) |
| -------- | --------------- | ----------------- |
| 英文       | Starvation      | Busy Waiting      |
| 原因       | 长期得不到资源         | 等待资源时不断检查         |
| CPU 是否占用 | 不一定             | 一定占用              |
| 进程状态     | 通常阻塞/等待         | 运行态               |
| 问题       | 公平性问题           | CPU 浪费问题          |
| 解决       | 提高优先级、FIFO      | 阻塞等待、信号量          |
解决了忙等就是实现了“让权等待”；只有**记录型信号量**解决了忙等问题
