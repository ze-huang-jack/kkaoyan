
# 3.2 虚拟内存管理 

### 三种内存管理方式的区别

| 特点       | 分页        | 分段        | 段页式            |
| -------- | --------- | --------- | -------------- |
| 划分依据     | 固定大小      | 程序逻辑      | 先逻辑再固定大小       |
| 大小是否固定   | 固定        | 不固定       | 段不固定，页固定       |
| 地址格式     | 页号 + 页内偏移 | 段号 + 段内偏移 | 段号 + 页号 + 页内偏移 |
| 是否有内部碎片  | 有         | 无         | 有（页导致）         |
| 是否有外部碎片  | 无         | 有         | 基本无            |
| 地址转换     | 页表        | 段表        | 段表 + 页表        |
| 是否符合程序逻辑 | 否         | 是         | 是              |
| 是否方便内存管理 | 很方便       | 较差        | 较方便            |
|          |           |           |                |

### 内存分配策略

| 策略       | 物理块数量 | 缺页时换谁 | 一句话             |
| -------- | ----- | ----- | --------------- |
| 固定分配局部置换 | 不变    | 自己    | 自己的床，自己换        |
| 可变分配全局置换 | 可变    | 自己或别人 | 缺页就想办法扩容，必要时借别人 |
| 可变分配局部置换 | 可变    | 自己    | 平时自己换，长期缺页再扩容   |


### 内部碎片和外部碎片的区别

| 存储管理方式 | 内部碎片 | 外部碎片          | 原因                    |
| ------ | ---- | ------------- | --------------------- |
| 固定分区   | ✔    | ✔             | 分区固定，可能分大了；连续分区也会留下空洞 |
| 动态分区   | ✘    | ✔             | 按需分配，没有分区内部浪费，但会产生空洞  |
| 分页     | ✔    | ✘             | 最后一页可能装不满；页可以离散存放     |
| 分段     | ✘    | ✔             | 段按需分配，但每段要求连续         |
| 段页式    | ✔    | ✘（通常按页管理物理内存） | 段内分页，因此继承分页特点         |
**先问自己两个问题：**

1. **浪费的空间是在已经分配给某个进程的里面吗？**
    - 是 → **内部碎片**。
2. **浪费的空间是在进程之间，属于空闲空间吗？**
    - 是 → **外部碎片**。

一句话记忆：

> **里面浪费叫内部碎片；外面零散叫外部碎片。**




### 运行用户程序要经历的三阶段

| 阶段  | 干什么                  | 输入     | 输出               |

### 装入时动态链接和运行时动态链接的区别

| 比较项         | 装入时动态链接     | 运行时动态链接     |     |
| ----------- | ----------- | ----------- | --- |
| 链接时间        | **程序装入内存时** | **程序运行过程中** |     |
| 是否开始运行前全部完成 | 是           | 否           |     |
| 启动速度        | 较慢          | 较快          |     |
| 内存占用        | 较大          | 较小          |     |
| 灵活性         | 较低          | 较高          |     |

- **装入时动态链接：装入时一次链接完，运行直接调用。**
- **运行时动态链接：运行到哪儿，链接到哪儿；需要什么，加载什么。**


### 要点 

对于算几级页表
%% 
物理地址= 物理块首地址 + 页内偏移量 = 物理块号 x 页面大小 + 页内偏移 
物理地址=物理块号 || 页内偏移  （ || 是**拼接**符号）
%%
先算，页内偏移位数= $log_2{(页面大小)}$
根据逻辑地址结构：高位页号位数+低位页内偏移量(页号数表示虚拟地址空间有多少个页面，如页号为20位，就代表一共有2^20个页面)
得出页号
一页的页表项数量=页号/页表项大小
那么级数=页号/一页的页表项数量（ 结果向上取整）

例：某个系统采用 32 位虚拟地址，页面大小为 4KB，每个页表项（PTE）大小为 4B。问：若要实现全虚拟空间映射，应该采用几级页表？
页内偏移量=12位
页号=32-12=20位
一个页面能容纳的页表项数量=2^12 / 2^2 = 2^10 共10位
20/10=2级页表

对于给一段代码求缺页中断次数的题的话，第一步看是按行访问还是按列访问，注意以下代码：
```
int a[128][128]
for(int i=0;i<128;i++) {
	for(int j=0;j<128;j++) {
	a[j][i]=0;
	}
}
```
是按列访问的
然后算一页能装下多少个元素，比如页框大小是128个字，一个整数占一个字，那么一页就有128个整数元素；又或者页框大小为512B，那么一个int占4B，即512/4=128个int/页
然后写出页1：``a[0][0], a[0][1] ... a[0][n] ... `` , 页2、页3等等以此类推

对于模拟LRU/FIFO算法的题，先看几个页框，然后看页面访问序列，只有后面出现现有内存里没有的页面才会发生缺页；而访问内存已经存在的页面，注意要更新该页面到页框格子的最后一位，表示最新访问过。

对于算平均内存有效访问时间(EAT=Effective Access Time)的题目，涉及到TLB快表命中率甚至缺页率的情况，平均访问时间的公式为：
- 查快表的时间为$\lambda$
- 快表命中率为a
- 对内存的访问时间为t(查页表或实际物理地址)
1. 没有TLB, 没有缺页
EAT= t + t = 2t
2. 有TLB，没有缺页
EAT = $a \times \lambda + (1-a) \times (\lambda + t) + t =2t + \lambda - t \times a$
这个可以这么理解$$\text{EAT} = \underbrace{[ a \times \lambda + (1-a) \times (\lambda + t) ]}_{\text{地址翻译时间}} + \underbrace{t}_{\text{最终取数时间}}$$
较为符合直觉的公式是：
EAT= $a \times (\lambda + t) + (1-a) \times (\lambda + 2t)$
亦即
平均访问时间=命中率 x 快表访问时间 + 不命中率 x (快表访问时间 + 页表访问时间) + 内存访问时间

访问次数 = 页表级数 $N$ + 1 次
