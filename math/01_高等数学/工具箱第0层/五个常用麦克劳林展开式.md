>[!warning] 经验之谈
>考研数学的极限题，不会出现结果等于0或者$\infty$ 的情况，一定是一个常数。因为不这样的话，任何人都能有50%的几率猜对，这就不符合考研数学的出题标准




使用泰勒展开的前提：
1. 展开变量必须趋向于展开中心


limitation：
- $x \to +\infty$ 不能用泰勒展开（unless 1/x)

展开到哪里才够:

展开到能够确定第一个主导项即可。
主导项是最低阶非零项

当两个函数相减的时候：
- **先找每个函数的主导项。**
- **观察这些主导项是否会相互抵消。**
- **如果不会抵消，就停。**
- **如果会抵消，就继续展开，直到出现第一个不抵消的项。**
- **这个第一个不抵消的项，就是整个表达式的主导项（最低阶非零项）。**

例子：
$$
\lim_{ x \to 0 } \frac{1}{x} - \frac{\ln(1+x)}{x\sin x}
$$
通分：
$$
\lim_{ x \to 0 } \frac {\sin x-\ln(1+x)}{x\sin x}
$$
- 这里易错点是把后面 $ln(1+x)$ 只展开到 $x$，因为这个分子真正的主导项是 $ln(1+x)$ 展开的第二项 $-\frac{x^2}{2}$, 而不是前面sinx的 $-\frac{x^3}{6}$ ,因为显然前者阶数更低，所以才是主导项（最低阶非零项）



>泰勒展开不是为了把函数全部展开，而是为了找到"第一个决定极限的非零项（主导项）"

一旦主导项出现，后面的高阶项全部属于
$$o(主导项)$$
它们已经不影响极限，可以立即停止。

## 1

$$

\lim_{ x \to 0 } \frac {e^{f(x)} - e^{g(x)} } { \dots} 

$$
通常可以尝试提取$e^{g(x)}$, 然后利用$e^t -1$ 的麦克劳林展开
或者直接展开



例子：
$$
\lim_{ x \to 0 } \frac{ e^{x^2} - e^{2-2\cos x}}{e^{x^4}-1}
$$
$$
\lim_{ x \to 0 }  \frac {e^{\tan x} - e^x}{x^3} = \frac{1}{3}
$$$$
\lim_{ x \to 0 } \frac{(1+x)^{\frac{3}{x}}-e^3}{x} = -\frac{3}{2}e^3
$$

$$
\lim_{ x \to 0^+ } \frac{x^x-1}{\ln x\ln(1-x)}=-1
$$
（25考研数学一真题T12)


有时, $e^{g(x)}$形如$e^{x\ln x}$, $e^{x\ln \sin x}$

$$
\lim_{ x \to 0 } \frac{(\tan x)^x-(\sin x)^x}{x[x-\ln(1+\sin x)]}=1
$$

## 2

$$
\lim_{ x \to \infty } \frac {x^n - x\sin x}{x^n-x\sin \frac{1}{x}} 
$$
通常可以尝试提取$x^n$
尝试构造出 ”一个趋近0的函数(无穷小量)  X 有界函数”， 最终等于0


例子：

$$
\lim_{ x \to \infty } \frac{x^2-x\sin x}{x^2+x\sin{\frac{1}{x}}} = 1
$$
分子分母同时除以 $x^2$

## 编号6

$$
\lim_{ n \to \infty } \frac{f(x)+g(x)}{\dots}
$$
可以构造  $1 + \frac{1}{\infty}$ 的形式

例子：

$$
\lim_{ n \to \infty } \frac{3^n+n^2}{3^{n+1}+(n+1)^2} = \frac{1}{3}
$$
这里可以分子分母同时除以 $3^n$

$$
\lim_{ n \to \infty } \frac{3^n \cdot \sqrt{ 3 }}{3^n+n^2}=\sqrt{ 3 }
$$
