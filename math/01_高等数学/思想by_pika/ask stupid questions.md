- 什么时候不能用（limitation）

| 问题              | 目的        |
| --------------- | --------- |
| ① 它是什么？         | 明确研究对象    |
| ② 为什么这样定义？      | 理解定义来源    |
| ③ 它真正描述什么？      | 抓住几何/物理意义 |
| ④ 它统一了哪些东西？     | 建立知识网络    |
| ⑤ 什么时候用？        | 学会应用      |
| ⑥ 什么时候不能用？      | 明确边界条件    |
| ⑦ 有没有更一般的版本？    | 学会推广      |
| ⑧ 能不能一句话概括？     | 提炼本质      |
| ⑨ 它和以前哪些知识是一回事？ | 建立联系      |
