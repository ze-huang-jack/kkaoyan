## 一、 四大等价条件

设区域 $D$ 是平面上的一个**单连通区域**（即区域内没有“洞”），函数 $P(x,y)$ 和 $Q(x,y)$ 在 $D$ 内具有连续的一阶偏导数。则以下四个条件在 $D$ 内是**充分必要且互为等价**的：

1. **路径无关性**：对 $D$ 内任意连接起点 $A$ 和终点 $B$ 的分段光滑曲线 $L$，积分值仅由起点和终点决定，与路径形态无关：(Related: [[牛顿莱布尼茨公式]])
    
    $$\int_L P\mathrm{d}x + Q\mathrm{d}y = \int_A^B P\mathrm{d}x + Q\mathrm{d}y$$
    
2. **闭曲线积分为零**：对 $D$ 内任意一条分段光滑的闭曲线 $C$，都有：
    
    $$\oint_C P\mathrm{d}x + Q\mathrm{d}y = 0$$
    
3. **偏导数交叉相等（判别法）**：在 $D$ 内恒成立：
    
    $$\frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y}$$
    
4. **存在原函数（全微分形式）**：在 $D$ 内存在某个二元函数 $u(x,y)$，使得 $P\mathrm{d}x + Q\mathrm{d}y$ 是 $u(x,y)$ 的[[全微分]]，即：(Related: [[牛顿莱布尼茨公式]])
    
    $$\mathrm{d}u = P\mathrm{d}x + Q\mathrm{d}y \quad \left(\text{其中 } \frac{\partial u}{\partial x} = P, \, \frac{\partial u}{\partial y} = Q\right)$$
    
    此时，积分值可直接表示为：$\int_{(x_1,y_1)}^{(x_2,y_2)} P\mathrm{d}x + Q\mathrm{d}y = u(x_2,y_2) - u(x_1,y_1)$。
    

> **⚠️ 注意：** > 使用 $\frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y}$ 的关键前提是**区域 $D$ 必须是单连通的**。如果区域内存在奇点（如原点 $(0,0)$ 处无定义），则不能直接得出路径无关的结论

第二类曲线积分与路径无关的条件下，有[[三种解法]]：
1. 直线路径
2. 折线路径（比如先沿 $x$ 轴走，再沿 $y$ 轴走）
3. 势函数法（找原函数直接代入上下限，类似于一维的微积分基本定理)

## 常见题型与解题策略

### 题型 1：判断积分是否与路径无关

- **方法**：
    
    1. 检查定义域是否为**单连通区域**；
        
    2. 计算偏导数 $\frac{\partial Q}{\partial x}$ 和 $\frac{\partial P}{\partial y}$，看两者是否恒相等。
        

### 题型 2：求参数或未知函数使积分与路径无关

- **思路**：利用等价条件 $\frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y}$ 建立关于待求参数或函数的微分方程，从而求解。
    
- **例题示范**：
    
    已知 $P(x,y) = 2xy + f(x)$，$Q(x,y) = x^2 + e^y$，若积分与路径无关且 $f(0) = 1$，求 $f(x)$。
    
    - **解法**：
        
        1. 计算偏导：$\frac{\partial P}{\partial y} = 2x$，$\frac{\partial Q}{\partial x} = 2x$。
            
        2. 发现无论 $f(x)$ 为何值，都有 $\frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y} = 2x$。
            
        3. 若题目中含有 $f'(x)$ 或其他待定关系，通过令偏导相等建立方程解出 $f(x)$ 即可。
            

### 题型 3：利用路径无关计算曲线积分（改换路径法）

当已知积分与路径无关，且原给定的曲线路径较为繁琐（如复杂的抛物线或折线）时，可以**用简单的直线段替换原路径**。

- **常用替代路径**：
    
    - **折线法**：连接 $(x_1,y_1) \to (x_2,y_1) \to (x_2,y_2)$。
        
        - 在第一段上，$\mathrm{d}y = 0$，$y$ 保持为 $y_1$；
            
        - 在第二段上，$\mathrm{d}x = 0$，$x$ 保持为 $x_2$。
            
- **计算公式**：
    
    $$\int_{(x_1,y_1)}^{(x_2,y_2)} P\mathrm{d}x + Q\mathrm{d}y = \int_{x_1}^{x_2} P(x, y_1)\mathrm{d}x + \int_{y_1}^{y_2} Q(x_2, y)\mathrm{d}y$$
    

### 题型 4：求原函数 $u(x,y)$ 并计算积分

若 $P\mathrm{d}x + Q\mathrm{d}y$ 是全微分，求原函数 $u(x,y)$ 常用以下两种方法：

1. **偏积分法（凑微分法）**：
    
    - 由 $\frac{\partial u}{\partial x} = P(x,y)$，两边对 $x$ 积分得 $u(x,y) = \int P(x,y)\mathrm{d}x + \phi(y)$；
        
    - 两边对 $y$ 求偏导，令其等于 $Q(x,y)$，从而解出 $\phi(y)$。
        
2. **线积分法（折线积分法）**：
    
    - 取基准点 $(x_0,y_0)$（通常取 $(0,0)$），原函数可直接写为：
        
        $$u(x,y) = \int_{x_0}^x P(t, y_0)\mathrm{d}t + \int_{y_0}^y Q(x, t)\mathrm{d}t + C$$


## 考法
题目已知曲线积分，判断是否与路径无关

题目已知路径无关，反过来求该曲线积分里的未知参数/未知函数

题目已知Pdx+Qdy是D内一函数u(x,y)的全微分，求$\int_{A}^{B}Pdx+Qdy$
