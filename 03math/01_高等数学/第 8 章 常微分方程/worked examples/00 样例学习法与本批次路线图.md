# 微分方程 worked examples：样例批次

> [!abstract] 一句话
> 这批材料按 [[Cognitive Load During Problem Solving by J. Sweller]] 的原则设计：**先样例、后解题；从已知正向推导；学习与测评分开；做完只复盘结构，不背数字。**
>
> 它**不是题库**，是"图式训练册"。每道题的目标不是算出答案，而是让一个"看到什么 → 想到什么"的条件反射长出来。答案只是训练的副产物。

相关：[[微分方程考点地图]] · [[齐次式]] · [[二阶常系数线性非齐次微分方程]] · [[欧拉方程]] · [[Cognitive Load During Problem Solving by J. Sweller]]

---

## 一、这批材料为什么长这样

Sweller 那篇论文的核心警示是：**新手直接刷"目标明确"的常规题，工作记忆会被"从目标倒推子目标"占满，没有余力归纳题型，题会做但图式没长出来。**

所以这批材料做了六个刻意的设计：

| 设计 | 对应论文原则 | 在本批次里的体现 |
|---|---|---|
| **完整样例先行** | worked-example effect | 每个 WE 都有完整推导，关键步骤标注"为什么" |
| **条件清单先于问题** | 降低手段-目的分析 | 每题第 0 步是"已知能推出什么"，不是"要求什么" |
| **无目标练习** | goal-free effect | 每个模块一篇 GF：不给唯一目标，尽量多推 |
| **结构复盘** | 图式形成 / 迁移 | 每题一张"结构卡"，只记触发条件与动作 |
| **渐隐** | expertise reversal | 模块 01–03 全样例；模块 04 的 WE-16、模块 05 的 WE-20 留 ▢ |
| **学习/测评分离** | 传统习题适合检验，不适合初学 | 06 检验区只给答案，不给解析 |

> [!important] 一句话用法
> **WE 用来"看懂"，GF 用来"正向推"，06 用来"测自己"。三者不要混用。**
> 初学阶段拿 06 的题硬扛，等于把 Sweller 论文里批评的那件事又做了一遍。

## 二、怎么用（按顺序做，不要跳）

### 第 1 遍：读样例（Day 0）

1. **先遮住下一步**。读完题目和"条件清单"，停下来问自己：*如果是我，下一步会做什么？为什么？*
2. 再往下看。每遇到一个 `> [!question]-` 折叠块，**先自己回答，再点开**。
3. 读完一题，**合上笔记，白纸重推一遍**。推不出来，只回去看"决策点"，不要从头重读。
4. 用一句话讲给自己听：**"这题属于哪类？触发条件是哪一句？关键动作是什么？"** 讲不出来 = 图式没形成，不是"粗心"。

### 第 2 遍：无目标练习（Day 1）

每个模块末尾有一篇 **GF（goal-free）**。它的问法不是"求 y"，而是"尽可能多地回答"。做的时候：

- **不要先看问题清单**，先顺着已知条件自己推，能推多少推多少；
- 推完再对照参考，看看自己漏了哪些"其实能推"的量；
- 这一步的价值不在答案，在**让你习惯"从已知出发"而不是"从问题倒推"**。

### 第 3 遍：渐隐变式（Day 3）

每个 WE 末尾有一个"变式"，答案在折叠块里。变式的设计原则是**只改一个条件**（一个符号、一个初值、一个 RHS），让你看清"结构没变，哪里变了"。

### 第 4 遍：混做（Day 7）

把 06 检验区 A 组的题**打乱顺序**做。不要按章节顺序，因为考场不会告诉你"这是第几章的题"。做完只对答案，错题回到对应的 WE 结构卡，**不要重读整道样例**。

### 第 5 遍：真题检验（Day 21）

做 06 检验区 B 组。B 组是"解方程 + 接续"的真题，目标是测**在完整题目里调用图式**的能力。其中几道是样例原题，隔几天再做，测的是**保持与提取**，不是即时记忆；真正的迁移测试在各 WE 的"变式"和 GF 里。

> [!tip] 间隔安排的道理
> 考研的保持期是几个月，所以复习间隔应以"周"为单位，而不是"每天复习昨天"。Day 0 → 1 → 3 → 7 → 21 只是一个骨架；你可以在每个节点只花 10–20 分钟做"白纸重推 + 一张结构卡"。

## 三、三条纪律

> [!warning] 纪律一：一次只学一个图式
> 不要一口气把一整个模块刷完。一个 WE 一个 WE 地过；每个 WE 之间至少隔几分钟，让"识别—动作"的链条沉淀。**连续刷 5 个样例而不重推，等于看了 5 个故事。**

> [!warning] 纪律二：卡住 90 秒就看样例
> 新手硬扛的搜索成本远大于看样例的收益。90 秒没有思路，就打开"条件清单"或"结构卡"，不要用"我再想想"消耗工作记忆。**看样例不是偷懒，是把算力从"搜索"挪到"归纳"。**

> [!warning] 纪律三：做完只记结构，不记数字
> 复盘时回答四个问题：
> 1. 这题属于哪一类？触发条件是哪一句？
> 2. 哪些条件是关键？哪些是迷惑信息？
> 3. 我在哪一步消耗的工作记忆最多？那一步能不能变成条件反射？
> 4. 如果只改一个数字/符号，题型会变成什么？
>
> **不要背答案，不要背数字。** 数字是壳，触发条件才是壳里的东西。

## 四、图式索引（开始前先看这张表）

这张表是全批次的"总图"。学完后，你应该能**不看表**把它复述出来。

| 你看到 | 第一反应 | 动作 | 样例 |
|---|---|---|---|
| 右边能写成 $f(x)g(y)$ | 可分离 | 分离 → 两边积分 | WE-01 |
| $y'+P(x)y=Q(x)$ | 一阶线性 | 积分因子 $\mathrm{e}^{\int P}$ | WE-02 |
| $y'=1/(x+y)$ 这类，对 $y$ 非线性 | 反函数 | $\frac{\mathrm{d}x}{\mathrm{d}y}=1/y'$ | WE-03 |
| 右边只含 $y/x$ | 齐次 | $u=y/x$ | WE-04 |
| $y'+Py=Qy^n$ | Bernoulli | $v=y^{1-n}$ | WE-05a |
| 出现 $yy'$ | 平方代换 | $u=y^2$ | WE-05b |
| $y'=f(x+y)$ | 平移代换 | $u=x+y$ | WE-16 |
| 常系数齐次 | 特征方程 | 三类根 → 三种通解 | WE-06 |
| RHS $=P_m(x)\mathrm{e}^{\lambda x}$ | 待定系数 | $x^kQ_m(x)\mathrm{e}^{\lambda x}$ | WE-07 / WE-08 |
| RHS 含三角 | 待定系数 | 共振则乘 $x$ | WE-09 |
| 给通解 / 给特解，求方程或参数 | 反求 | 读特征根 + 代回 | WE-10 / WE-11 |
| 给多个特解 | 解的结构 | 两两相减得齐次解 | WE-12 |
| 方程里没有 $y$ | 缺 $y$ 降阶 | $p=y'$，$y''=p'$ | WE-13 |
| 方程里没有 $x$ | 缺 $x$ 降阶 | $p=y'$，$y''=p\frac{\mathrm{d}p}{\mathrm{d}y}$ | WE-14 |
| $x^2y''+pxy'+qy=f(x)$ | 欧拉方程 | $x=\mathrm{e}^t$，$D(D-1)$ | WE-15 |
| 几何条件（距离/截距/面积） | 翻译 | 先写解析式，再列方程 | WE-17 |
| 物理/变化率（阻力 $\propto v$ 等） | 建模三步 | 设量 → 列式 → 定初值 | 模块 05 附录 |
| 解完方程问渐近线 | 接续 | $k=\lim y/x$，$b=\lim(y-kx)$ | WE-18 |
| 反常积分 + 微分方程 | 积分原方程 | 用 $f(\infty)=f'(\infty)=0$ | WE-19 |
| $g=f(x/y)$ + 二阶偏导齐次组合 | 欧拉型 | $u=x/y$ → $u^2f''+uf'=\cdots$ | WE-20 |

> [!note] 这张表怎么用
> 做变式卡住时，**先看"第一反应"那一列**，不要看"动作"那一列。如果第一反应想不起来，说明缺的是识别，不是计算；如果第一反应对了但动作卡住，才回去看样例的计算步骤。

## 六、复盘模板（每道错题填一次）

复制下面这段到错题本：

```markdown
## 错题：<题号 / 来源>
- 属于哪一类：
- 触发条件（题面里的哪一句）：
- 我卡在哪一步：
- 这一步的正确动作：
- 如果只改一个条件，会变成哪一类：
- 对应 WE：
```

> [!important] 复盘的重点
> **不是"我为什么算错"，而是"我为什么没认出来"。**
> 算错是执行问题，认不出是图式问题。前者练计算，后者才需要回到样例。

## 七、边界说明

- **本批次不覆盖**：全微分方程 / 路径无关（与第 9 章一起练，见 [[微分方程考点地图]] 第五节"伪装题"）；幂级数解法（2002、2007 的交叉题）；复杂物理建模（只给一个减速伞样例，其它物理题按模块 05 附录的"三步建模法"迁移）。
- **前置技能**：换元积分、分部积分、初等函数定义域。如果卡在积分，标记为"积分债"，不要误判为"ODE 不会"。
- **答案可信度**：本批**计算题的答案**已用 sympy 逐题回代复核（2026-10-18）；证明题与"结构判断"类答案按定义/定理核对。但**样例的价值在过程，不在答案**。请你自己动手推一遍，尤其是折叠块里的"为什么"。
- **2026 真题不在库内**：本批次基于 1987–2025 真题库与 [[微分方程考点地图]]；2026 的 ODE 题补入后，06 检验区需要更新。

> 新手解题时，大脑的绝大部分算力用在"把题做出来"；如果题目只有一个明确目标，手段-目的分析就会占满工作记忆，图式反而没有资源生长。
