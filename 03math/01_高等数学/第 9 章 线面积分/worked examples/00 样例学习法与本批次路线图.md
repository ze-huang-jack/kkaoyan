# 线面积分 worked examples：样例批次

> [!abstract] 一句话
> 这批材料按 [[Cognitive Load During Problem Solving by J. Sweller]] 的原则设计：**先样例、后解题；从已知正向推导；学习与测评分开；做完只复盘结构，不背数字。**
>
> 它**不是题库**，是"图式训练册"。每道题的目标不是算出答案，而是让一个"看到什么 → 想到什么"的条件反射长出来。答案只是训练的副产物。

相关：[[线面积分真题考察报告]] · [[曲线积分]] · [[曲面积分]] · [[格林公式]] · [[如何利用高斯公式解曲面积分]] · [[平面曲线积分与路径无关]] · [[Cognitive Load During Problem Solving by J. Sweller]]

---

## 一、这批材料为什么长这样

线面积分的真题有一个很稳定的结构：**高斯公式 20 次、格林公式 12 次，两者占了全部核心题的 42%；剩下的是第一类线/面、第二类曲面直接投影、斯托克斯、路径无关和概念题。**（数字见 [[线面积分真题考察报告]]。）

也就是说，这一章不是"十个平行的公式"，而是**三张网 + 两个基础动作**：

- 三张网：格林、高斯、斯托克斯。
- 两个基础动作：**补**（补线/补面）和**挖**（挖掉奇点）。

所以这批材料做了六个刻意的设计：

| 设计 | 对应论文原则 | 在本批次里的体现 |
|---|---|---|
| **完整样例先行** | worked-example effect | 每个 WE 都有完整推导，关键步骤标注"为什么" |
| **条件清单先于问题** | 降低手段-目的分析 | 每题第 0 步是"已知能推出什么"，不是"要求什么" |
| **无目标练习** | goal-free effect | 每个模块一篇 GF：不给唯一目标，尽量多推 |
| **结构复盘** | 图式形成 / 迁移 | 每题一张"结构卡"，只记触发条件与动作 |
| **渐隐** | expertise reversal | 模块 04 的 WE-18、模块 05 的 WE-20 在关键步骤设 ▢ 自检 |
| **学习/测评分离** | 传统习题适合检验，不适合初学 | 06 检验区只给答案，不给解析 |

> [!important] 一句话用法
> **WE 用来"看懂"，GF 用来"正向推"，06 用来"测自己"。三者不要混用。**

## 二、怎么用（按顺序做，不要跳）

### 第 1 遍：读样例（Day 0）

1. **先遮住下一步**。读完题目和"条件清单"，停下来问自己：*如果是我，下一步会做什么？为什么？*
2. 再往下看。每遇到一个 `> [!question]-` 折叠块，**先自己回答，再点开**。
3. 读完一题，**合上笔记，白纸重推一遍**。推不出来，只回去看"决策点"，不要从头重读。
4. 用一句话讲给自己听：**"这题属于哪类？触发条件是哪一句？关键动作是什么？"** 讲不出来 = 图式没形成，不是"粗心"。

### 第 2 遍：无目标练习（Day 1）

每个模块末尾有一篇 **GF（goal-free）**。它的问法不是"求这个积分"，而是"尽可能多地回答"。做的时候：

- **不要先看问题清单**，先顺着已知条件自己推，能推多少推多少；
- 推完再对照参考，看看自己漏了哪些"其实能推"的量；
- 这一步的价值不在答案，在**让你习惯"从已知出发"而不是"从问题倒推"**。

### 第 3 遍：渐隐变式（Day 3）

每个 WE 末尾有一个"变式"，答案在折叠块里。变式的设计原则是**只改一个条件**（一个符号、一个初值、一个侧、一个方向），让你看清"结构没变，哪里变了"。

### 第 4 遍：混做（Day 7）

把 06 检验区 A 组的题**打乱顺序**做。不要按章节顺序，因为考场不会告诉你"这是第几章的题"。做完只对答案，错题回到对应的 WE 结构卡，**不要重读整道样例**。

### 第 5 遍：真题检验（Day 21）

做 06 检验区 B 组。B 组是"补线/补面/挖洞/斯托克斯"的综合题，目标是测**在完整题目里调用图式**的能力。其中几道是样例原题，隔几天再做，测的是**保持与提取**，不是即时记忆；真正的迁移测试在各 WE 的"变式"和 GF 里。

> [!tip] 间隔安排的道理
> 考研的保持期是几个月，所以复习间隔应以"周"为单位，而不是"每天复习昨天"。Day 0 → 1 → 3 → 7 → 21 只是一个骨架；你可以在每个节点只花 10–20 分钟做"白纸重推 + 一张结构卡"。

## 三、三条纪律

> [!warning] 纪律一：一次只学一个图式
> 不要一口气把一整个模块刷完。一个 WE 一个 WE 地过；每个 WE 之间至少隔几分钟，让"识别—动作"的链条沉淀。**连续刷 5 个样例而不重推，等于看了 5 个故事。**

> [!warning] 纪律二：卡住 90 秒就看样例
> 新手硬扛的搜索成本远大于看样例的收益。90 秒没有思路，就打开"条件清单"或"结构卡"，不要用"我再想想"消耗工作记忆。**看样例不是偷懒，是把算力从"搜索"挪到"归纳"。**

> [!warning] 纪律三：做完只记结构，不记数字
> 复盘时回答四个问题：
> 1. 这题属于哪一类？触发条件是哪一句？
> 2. 哪些条件是关键？哪些是迷惑信息？
> 3. 我在哪一步消耗的工作记忆最多？那一步能不能变成条件反射？
> 4. 如果只改一个数字/符号/方向，题型会变成什么？
>
> **不要背答案，不要背数字。** 数字是壳，触发条件才是壳里的东西。

## 四、图式索引（开始前先看这张表）

这张表是全批次的"总图"。学完后，你应该能**不看表**把它复述出来。

| 你看到 | 第一反应 | 动作 | 样例 |
|---|---|---|---|
| $\int_L f\,\mathrm ds$ | 第一类曲线 | 参数化，$ds=\sqrt{x'^2+y'^2}\,\mathrm dt$；方向无关 | WE-01 |
| 曲线关于坐标轴对称，被积函数有奇偶性 | 第一类曲线 + 对称 | 奇函数消去；偶函数乘 2，或用曲线方程化常数 | WE-02 |
| $\int_L P\,\mathrm dx+Q\,\mathrm dy$，$L$ 是圆弧/抛物线 | 第二类曲线直接计算 | 参数化，**方向决定积分限** | WE-03 |
| $L$ 是折线/分段曲线 | 第二类曲线分段 | 按段代入，注意每段 $\mathrm dy$ 的符号 | WE-04 |
| 空间曲线 + 对称表达式 | 第一类曲线 + 轮换对称 | 用曲线方程和 $x+y+z$ 之类的关系 | WE-05 |
| 平面闭曲线，正向 | 格林公式 | $\oint P\,\mathrm dx+Q\,\mathrm dy=\iint(Q_x-P_y)\,\mathrm dx\mathrm dy$ | WE-06 |
| 平面非闭曲线 | 格林 + 补线 | 补一条好算的直线段，注意闭合方向 | WE-07 |
| 分母有奇点，曲线围住奇点 | 格林 + 挖洞 | 换一个小圆/小椭圆，算它的积分 | WE-08 |
| "与路径无关" | $P_y=Q_x$ | 在单连通区域验证，解参数 | WE-09 |
| 已知是某函数的梯度/全微分 | 势函数 | 偏积分，定常数 | WE-10 |
| $\iint_\Sigma f\,\mathrm dS$ | 第一类曲面 | 投影，$dS=\sqrt{1+z_x^2+z_y^2}\,\mathrm dx\mathrm dy$ | WE-11 |
| 曲面关于坐标面对称 | 第一类曲面 + 对称 | 奇函数消去；偶函数乘 2，或用对称性平均化 | WE-12 |
| $\iint_\Sigma R\,\mathrm dx\mathrm dy$，曲面 $z=z(x,y)$ | 第二类曲面直接投影 | 上侧取 $+$，下侧取 $-$ | WE-13 |
| 要把 $\mathrm dy\mathrm dz,\mathrm dz\mathrm dx$ 化成 $\mathrm dx\mathrm dy$ | 第二类曲面转换 | $(\mathrm dy\mathrm dz,\mathrm dz\mathrm dx,\mathrm dx\mathrm dy)=(-z_x,-z_y,1)\mathrm dx\mathrm dy$ | WE-14 |
| 闭曲面，外侧 | 高斯公式 | $\oiint P\,\mathrm dy\mathrm dz+\cdots=\iiint(P_x+Q_y+R_z)\,\mathrm dV$ | WE-15 |
| 非闭曲面 | 高斯 + 补面 | 补圆盘/平面，注意补面的侧 | WE-16 |
| 曲面是椭球/柱面的一部分，补面后高斯 | 高斯 + 补面 | 先看补哪块最简单，再算 $\operatorname{div}$ | WE-17 |
| 被积函数在原点奇异，曲面围住原点 | 高斯 + 挖洞 | 换一个小球，算 $4\pi$ | WE-18 |
| 空间闭曲线，平面与曲面交线 | 斯托克斯 | 选平面片，右手法则定法向 | WE-19 |
| 空间闭曲线 + 复杂被积函数 | 斯托克斯 + 投影 | 先算 $\operatorname{curl}$，再看 $\operatorname{curl}\cdot\boldsymbol n$ 是否化简 | WE-20 |
| 求 $\operatorname{div}$ / $\operatorname{rot}$ | 公式 | 直接代公式 | 附录 A |
| 变力做功 / 曲面质量 | 应用题三步法 | 设量 → 列积分 → 算 | 附录 B |

> [!note] 这张表怎么用
> 做变式卡住时，**先看"第一反应"那一列**，不要看"动作"那一列。如果第一反应想不起来，说明缺的是识别，不是计算；如果第一反应对了但动作卡住，才回去看样例的计算步骤。

## 六、复盘模板（每道错题填一次）

复制下面这段到错题本：

```markdown
## 错题：<题号 / 来源>
- 属于哪一类：
- 触发条件（题面里的哪一句）：
- 我卡在哪一步：
- 这一步的正确动作：
- 如果只改一个条件，会变成哪一类：
- 对应 WE：
```

> [!important] 复盘的重点
> **不是"我为什么算错"，而是"我为什么没认出来"。**
> 算错是执行问题，认不出是图式问题。前者练计算，后者才需要回到样例。

## 七、边界说明

- **本批次覆盖 20 个核心图式**，不是 77 道真题的题库。真题的完整统计、分值和考法分布见 [[线面积分真题考察报告]]；本批次只挑"最能长出图式"的题。
- **不覆盖**：纯梯度/方向导数（属第 5 章）；定积分物理应用（1999 七、2003 六）；复杂的第一类曲面几何题（2010 19 这类，知道"先求轨迹再投影"即可）。
- **前置技能**：参数方程、极坐标、二重积分、偏导数。如果卡在积分，标记为"积分债"，不要误判为"线面积分不会"。
- **答案可信度**：本批次的 20 道 WE 全部取自 1987–2025 真题，答案与 `solutions/` 里的官方解析（或 2025 卷内解析）逐题对照过。变式与 GF 的答案按同一方法手算复核。
- **2026 真题**：本批次没有把 2026 (19) 放进 WE，因为原卷 OCR 有缺字、且官方答案尚未入库；它出现在 [[线面积分真题考察报告]] 的统计里，等答案入库后再补。
