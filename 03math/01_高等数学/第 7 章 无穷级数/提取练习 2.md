# 一、抽象级数
## 反例
$\frac{1}{n}$, $\frac{(-1)^n}{n}$

## 性质
收敛 + 收敛 = 收敛
收敛 + 发散 = 发散
发散 + 发散 = 不确定

收敛 * 收敛 = 不确定
收敛 * 发散 = 不确定
发散 * 发散 = 不确定

发散级数加了绝对值后也一定发散
加了绝对值的级数收敛，原级数也一定收敛（绝对收敛）


## 比较判别法

设两个正项级数 $\sum u_{n}$， $\sum v_{n}$，当$u_{n}<v_{n}$, 若$\sum v_{n}$收敛，那么 $\sum u_{n}$收敛；若 $u_{n}$发散，则$v_{n}$发散。


# 二、数项级数的敛散性
## 1. 级数收敛的必要条件
若任意项级数$\sum u_{n}$收敛，则$u_{n}\to0$; 存在 $M>0$, 使得 $|u_{n}|\leq M$

## 2. 交错级数的莱布尼茨判别法
设有交错级数 $\sum (-1)^n u_{n}$，当 $u_{n}\to0$，且 $u_{n}$单调递减时，级数收敛。

## 3. 正项级数的比值法和根值法
### 比值法
设有正项级数$\sum u_{n}$，令$p=\lim_{ n \to \infty } \frac{u_{n+1}}{u_{n}}$，当$0<p<1$时，级数绝对收敛；当$p>1$时，级数发散；当$p=1$时，级数的敛散性不确定。

为什么$p=1$时，级数敛散性不确定呢？看例子
$\sum u_{n}=\frac{1}{n}$, 该级数是发散的，但是 $p=1$

$\sum u_{n}= \frac{(-1)^n}{n}$, 该级数是收敛的，但是 $p=1$

### 根值法
设有正项级数$\sum u_{n}$，令$p=\lim_{ n \to \infty} \sqrt[n]{ u_{n} }$，当$0<p<1$时，级数绝对收敛；当$p>1$时，级数发散；当$p=1$时，级数的敛散性不确定。

## 4. 正项级数的比较审敛法的极限形式

设有两个正项级数$\sum u_{n}$, $\sum v_{n}$, 令 $q=\lim_{ n \to \infty } \frac{u_{n}}{v_{n}}$, 则当 $0<q<+\infty$，两个级数同敛散性；当$q=0$, 则$u_{n}<v_{n}$, 那么当 $v_{n}$收敛时，$u_{n}$收敛；当 $q=\infty$，则$u_{n}>v_{n}$, 那么当$u_{n}$收敛时，$v_{n}$收敛。

## 5. 利用泰勒展开
一般级数是减法，需要做泰勒展开，确定主导性

## 6. 正项级数的积分判别法

设函数 $f(n)$在区间 $[1,\infty]$上非负、单调递减、连续时，则级数$\sum f(n)$ 与反常积分$\int_{1}^{\infty} f(x) \, dx$ 同敛散。

那么问题就从判断级数的敛散性转化为判断反常积分的敛散性，一般用直接定义法判断反常积分的敛散性：
1. 将无穷设为变量，令这个变量趋近无穷
2. 解定积分
3. 如果算出来的是有限实数，则反常积分收敛；否则，发散


$\sum \frac{1}{n\ln n}$ 发散


注意**带参数的数项级数**的敛散性判断要分类讨论参数
