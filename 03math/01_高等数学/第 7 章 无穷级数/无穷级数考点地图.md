# 无穷级数考点地图

> [!abstract] 一句话结论
> **1987–2025 共 39 套数学一真题，级数题无一缺席**（唯一"疑似空年"的 2018 年第(3)题就是级数题）。它不是"高频考点"，是**铁打的必考**。近五年分值 8.7 分/年，和一元积分、二次型同级。

## 一、考点结构（★ = 真题权重）

### A. 常数项级数敛散性 ★★★
出现在**选择/填空**，是小题的主力。

- 收敛定义与基本性质
	- 部分和 $S_n$ 与 $\lim S_n$ 存在
	- 线性性质
	- **必要条件**：$\sum u_n$ 收敛 $\Rightarrow \lim u_n = 0$（反之不成立）见 [[无穷级数#编号1]]
- 正项级数**四把刀**
	- 比较判别法（含极限形式）→ [[遇到正项级数考虑比较审敛法]]
	- 比值判别法 → [[如何利用比值审敛法判断正项级数敛散性]]
	- **根值判别法**（柯西）← *笔记缺口*
	- 积分判别法 → [[如何利用积分判别法判断级数敛散性]]
- **三把标尺**（拿来比较的基准）
	- 几何级数 $\sum aq^n$：$|q|<1$ 收敛
	- p 级数 $\sum \frac{1}{n^p}$：$p>1$ 收敛 → [[p级数]]
	- 调和级数 $\sum\frac1n$ 发散 → [[调和级数]]
- 交错级数与**莱布尼茨判别法** → [[无穷级数#编号2]]
- 绝对收敛 vs 条件收敛 → [[绝对收敛和条件收敛]]
- ⚠️ **抽象级数性质题**（"设 $\sum a_n$ 收敛，则下列必收敛的是"）——选择题最难的一类，见第四节

### B. 幂级数 ★★★
出现在**解答题**，是唯一可能出大分的地方。

阿贝尔定理 → 收敛半径 → 收敛域（**端点单独讨论**）→ 逐项求导/积分 → **求和函数** → **函数展开**

### C. 傅里叶级数（数一独有）★★
只在**填空**出现，近三年连考。见第三节。

### D. 函数项级数 ★
偶尔与 A/B 混合出现（2021、2022 考过收敛域）。

## 三、七大考法 + 对应工具

### ① 傅里叶估值（🥇 投入 1 小时，稳拿 5 分）

**题型**：给 $f(x)$ 和一个和函数 $S(x)$，求 $S(x_0)$ 的值。**不需要算任何积分。**

**三步法**：
1. **周期性平移**：把 $x_0$ 平移进 $[0,2l]$ 或 $[-\pi,\pi]$
2. **奇偶性变号**：正弦级数 $\Rightarrow S(x)$ 是奇函数，$S(-x)=-S(x)$；余弦级数 $\Rightarrow S(x)$ 是偶函数，$S(-x)=S(x)$
3. **收敛定理取值**：连续点取 $f(x_0)$；**间断点取** $\dfrac{f(x_0-0)+f(x_0+0)}{2}$

**真题模板（2025 第12题）**：

> $f(x)=\begin{cases}0, & 0\le x<\frac12\\ x^2, & \frac12\le x\le1\end{cases}$，其傅里叶级数为 $\sum b_n\sin n\pi x$，$S(x)$ 为和函数，求 $S\left(-\frac72\right)$。

解：正弦级数 ⇒ 奇函数、周期 2
$$S\left(-\tfrac72\right)=S\left(-\tfrac72+4\right)=S\left(\tfrac12\right)=\frac{f(\tfrac12^-)+f(\tfrac12^+)}{2}=\frac{0+\tfrac14}{2}=\frac18$$

**练这三道就够**：2023(13)、2024(13)、2025(12)

**必背公式**：
- 周期 $2\pi$：$a_n=\frac1\pi\int_{-\pi}^{\pi}f(x)\cos nx\,\mathrm dx$，$b_n=\frac1\pi\int_{-\pi}^{\pi}f(x)\sin nx\,\mathrm dx$
- 周期 $2l$：角频率变成 $\frac{n\pi x}{l}$，前面系数变 $\frac1l$
- 偶延拓 → $b_n=0$（余弦级数）；奇延拓 → $a_n=0$（正弦级数）

### ② 幂级数求和函数（🥈 解答题主力，需 1 周）

**五个母函数**（在[[五个常用麦克劳林展开式]]之外必须补上）：

$$\frac{1}{1-x}=\sum_{n=0}^{\infty}x^n\ (|x|<1),\qquad \frac{1}{1+x}=\sum_{n=0}^{\infty}(-1)^nx^n\ (|x|<1)$$

$$\frac{1}{(1-x)^2}=\sum_{n=1}^{\infty}nx^{n-1}\ (|x|<1)$$

$$\arctan x=\sum_{n=0}^{\infty}\frac{(-1)^n}{2n+1}x^{2n+1}\ (|x|\le1)$$

**两条运算**：逐项求导、逐项积分 —— **收敛半径都不变**（1997、2015 都考过这条）

**套路识别表**：

| 看到什么 | 怎么做 |
|---|---|
| 系数含 $n^2-n$ | 拆出 $n(n-1)$，配二阶导 $\left(\sum x^n\right)''$ |
| 分母含 $n$ | 先求导消 $n$，或先积分生 $n$ |
| 分母含 $2n$ 或 $2n-1$ | 往 $\arctan$、$\ln\frac{1+x}{1-x}$ 上凑，用 $x^2$ 代换 |
| 只有偶次幂（**缺项**） | 令 $t=x^2$ 化标准型 |
| 需要 $x=0$ 处的值 | **单独定义**（固定失分点） |

> [!tip] 最易错的两处
> - **端点**：求出 $R$ 后必须代 $x=\pm R$ 单独判敛散
> - **$x=0$**：提出 $\frac1x$ 或除以 $x$ 后，$x=0$ 处要单独写（例：1987 六、1996 五）

**必做真题（由易到难）**：2017(12) → 2019(11) → 2010(18) → 2020(17) → 2012(17)

### ③ 函数展开成幂级数（间接展开法）

**套路**：先求导化简成有理式 → 部分分式或几何级数展开 → 再逐项积分还原

**必做**：1994 三(2)、2001 五、2003 四、2006 三(17)

### ④ 数项级数敛散性判别（选择/填空）

**判别法选择决策树**：
```
通项 → 0 吗？ 否 → 发散（必要条件）
   ↓ 是
是交错级数吗？ 是 → 莱布尼茨
   ↓ 否
正项级数 → 通项含 n! 或 a^n → 比值法
          → 通项是 n 次方整体 → 根值法
          → 有理分式 → 比较法（极限形式）
          → 含 1/(n ln n) 型 → 积分判别法
```

### ⑤ 抽象级数性质题（选择题最难）

**解法只有两条路**：
1. **部分和定义法**：把新级数的部分和用 $S_n$ 表示出来，看极限是否存在
2. **举反例排除**：见第五节的反例库

### ⑥ 收敛半径 / 收敛域（送分但有两个陷阱）

- 公式法 $R=\lim\left|\dfrac{a_n}{a_{n+1}}\right|$
- ⚠️ **缺项幂级数**（如 $\sum a_nx^{2n}$）**不能用上面的公式**，必须用比值法或根值法直接算
- ⚠️ **端点必须单独讨论**（2022(14) 就是靠 $x=-1$ 发散定出 $a=-1$）
- **半径不变性**：乘 $n$、逐项求导、逐项积分，半径都不变

### ⑦ 幂级数 + 微分方程（交叉考点）

给递推式 $a_{n+2}=\frac{2}{n+1}a_n$ → 证 $y''-2xy'-4y=0$ → 解微分方程 → 得和函数

**必做**：2007(20)、2013(16)、2020(17)

## 五、级数反例库

> [!note] 为什么需要
> 抽象级数性质题（"下列必收敛的是"）的官方解法就是**举反例排除**。这些反例全部来自真题标准答案，背下来即可。

| 反例 | 能推翻的命题 | 出处 |
|---|---|---|
| $a_n=\dfrac{(-1)^n}{\sqrt n}$ | $\sum a_n$ 收敛 $\nRightarrow$ $\sum a_n^2$ 收敛；$\nRightarrow$ $\sum\lvert a_n\rvert$ 收敛 | 2006(9) |
| $a_n=\dfrac{1}{n\ln(n+1)}$ | $na_n\to0$ $\nRightarrow$ $\sum a_n$ 收敛 | 2004(9) |
| $a_n=\dfrac{1}{n^{3/2}}$ | $\sum a_n$ 收敛 $\nRightarrow$ $n^2a_n\to0$ | 2004(9) |
| $a_n=\dfrac{1}{\ln(n+1)}$ | $\sum a_n$ 发散 $\nRightarrow$ $na_n\to\lambda\ne0$ | 2004(9) |
| $a_n=\dfrac{(-1)^n}{\ln(n+1)}$ | $\sum a_n$ 收敛 $\nRightarrow$ $\sum(-1)^n\dfrac{a_n}{n}$ 收敛 | 2000(3) |
| $a_n=b_n=\dfrac{1}{\sqrt n}$ | $\sum\lvert b_n\rvert$ 发散 $\nRightarrow$ 相关结论 | 2009(4) |
| $u_n=\dfrac{(-1)^n}{n}$ | $\sum u_n$ 收敛 $\nRightarrow$ $\sum(-1)^n\dfrac{u_n}{n}$ 收敛 | 2006(9) |
| $u_n=\dfrac{(-1)^{n-1}}{n}$ | $\sum u_n$ 收敛 $\nRightarrow$ $\sum(u_{2n-1}-u_{2n})$ 收敛 | 2000(3) |

**必做六题**：2000(3)、2004(9)、2006(9)、2009(4)、2023(4)、2025(2)
