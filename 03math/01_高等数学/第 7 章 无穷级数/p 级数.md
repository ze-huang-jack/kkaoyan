
# what it is 
$\frac{1}{n^p}$

p=1 时，变成调和级数，发散
p>1 时，收敛的，$\frac{1}{n^2}$, $\frac{1}{n^{1.5}}$ 都是收敛的
0<p<1 时，发散， $\frac{1}{\sqrt{ n }}$发散




>[!abstract] p级数的敛散性
>$$\sum_{n=1}^{\infty} \frac{1}{n^p}$$
>- **$p > 1$**：收敛
>- **$p \leq 1$**：发散


## 特殊情形

- **$p = 1$**：[[调和级数]] $\sum \frac{1}{n}$，发散。
- **$p = 2$**：$\sum \frac{1}{n^2} = \frac{\pi^2}{6}$（Basel问题，考研常考的求和结论）
