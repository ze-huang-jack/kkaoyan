**格林公式本质上对单连通区域和复连通区域都适用**，只不过复连通区域的公式要写成
$$\oint_{C^+} (P \, dx + Q \, dy) + \oint_{C_r^-} (P \, dx + Q \, dy) = \iint_{D'} \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) dx \, dy$$

**这里+号表示逆时针，-号表示顺时针**，但这两个曲线边界都是正向的，在格林公式里正向是区域在这条曲线的左手边



如果把这个公式用更通用的数学语言写出来，本质上就是：

$$\iint_{D'} \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) dx \, dy = \oint_{\partial D'} (P \, dx + Q \, dy)$$

这里的 $\partial D'$ 就代表**区域 $D'$ 的所有正向边界之和**。

- 对于**只有一个洞**的区域，$D'$ 的边界就是外圈正向 $C^+$ 和内圈正向 $C_r^-$，所以展开写就是你写的这个等式：
    
    $$\oint_{\partial D'} = \oint_{C^+} + \oint_{C_r^-}$$
    
- 如果区域里有**多个洞**（比如有 3 个奇点，挖了 3 个小圆），公式也完全一样，只需要把每个洞的顺时针边界积分都加进来即可：
    
    $$\oint_{C^+} + \oint_{C_{r1}^-} + \oint_{C_{r2}^-} + \oint_{C_{r3}^-} = \iint_{D'} \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) dx \, dy$$
