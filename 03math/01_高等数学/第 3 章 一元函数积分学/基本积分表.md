
高等数学（微积分）中最核心的基本积分公式通常被称为**基本积分表**。这些公式是微积分运算的根基，主要分为**直接反推自导数公式**的（基本初等函数）和**衍生出来的常见形式**（凑微分）。

以下是高数课本（如同济版《高等数学》）中最标准的24个基本积分公式：

### 一、基础幂函数与常数（最基本的起点）

1.  **$\int 0 \, dx = C$** 
2.  **$\int 1 \, dx = \int dx = x + C$**
3.  **$\int x^{\mu} \, dx = \frac{x^{\mu+1}}{\mu+1} + C \quad (\mu \neq -1)$** 
    *(注：这是最常用的公式，涵盖了所有幂函数，除了 $x^{-1}$)*

---

### 二、倒数与分式（特别指向 $x^{-1}$）

4.  **$\int \frac{1}{x} \, dx = \ln |x| + C$** 
    *(千万注意绝对值符号不能丢，定义域为$x\neq0$)*

---

### 三、指数函数（导数等于自身的特例）

5.  **$\int a^x \, dx = \frac{a^x}{\ln a} + C \quad (a>0, a\neq 1)$**
6.  **$\int e^x \, dx = e^x + C$** 
    *(由公式5当$a=e$时得出)*

---

### 四、三角函数（6个基础三角函数）

7.  **$\int \sin x \, dx = -\cos x + C$**
8.  **$\int \cos x \, dx = \sin x + C$**
9.  **$\int \sec^2 x \, dx = \tan x + C$** 
    *(因为 $(\tan x)' = \sec^2 x$)*
10. **$\int \csc^2 x \, dx = -\cot x + C$** 
    *(因为 $(\cot x)' = -\csc^2 x$)*
11. **$\int \sec x \tan x \, dx = \sec x + C$** 
    *(因为 $(\sec x)' = \sec x \tan x$)*
12. **$\int \csc x \cot x \, dx = -\csc x + C$** 
    *(因为 $(\csc x)' = -\csc x \cot x$)*

---

### 五、反三角函数与根式（涉及 $\sqrt{}$ 的积分）

13. **$\int \frac{1}{\sqrt{1-x^2}} \, dx = \arcsin x + C = -\arccos x + C$**
14. **$\int \frac{1}{1+x^2} \, dx = \arctan x + C = - \operatorname{arccot} x + C$

---

### 六、双曲函数（部分理工科课本涉及）

15. **$\int \sinh x \, dx = \cosh x + C$**
16. **$\int \cosh x \, dx = \sinh x + C$**

---

### 七、衍生出的常见“凑微分”标准形式（重点补充）

在计算不定积分时，以下**变体公式**极其常用，高数课本通常将它们列在基本积分表的末尾：

17. **$\int \tan x \, dx = -\ln |\cos x| + C$** 
18. **$\int \cot x \, dx = \ln |\sin x| + C$** 
19. **$\int \sec x \, dx = \ln |\sec x + \tan x| + C$** 
20. **$\int \csc x \, dx = \ln |\csc x - \cot x| + C$** 
21. **$\int \frac{1}{\sqrt{a^2 - x^2}} \, dx = \arcsin \frac{x}{a} + C \quad (a>0)$**
22. **$\int \frac{1}{a^2 + x^2} \, dx = \frac{1}{a} \arctan \frac{x}{a} + C \quad (a>0)$**
23. **$\int \frac{1}{x^2 - a^2} \, dx = \frac{1}{2a} \ln \left| \frac{x-a}{x+a} \right| + C \quad (a>0)$**
24. **$\int \frac{1}{\sqrt{x^2 \pm a^2}} \, dx = \ln |x + \sqrt{x^2 \pm a^2}| + C$** 
    *(常用三角代换或双曲代换推导)*
