
一般曲线的微元$ds= \sqrt{(dx^2+dy^2)}$
圆弧的微元$ds=rd\theta$


面积元$dS=rdrd\theta$




| 对象    | 微元     | 公式                                           |
| ----- | ------ | -------------------------------------------- |
| 长度    | (dx)   | 直线上的小长度                                      |
| 弧长    | (ds)   | ($\sqrt{1+y'^2},dx)$                         |
| 面积    | (dxdy) | 平面小矩形                                        |
| 极坐标面积 | (dA)   | $(r,dr,d\theta)$                             |
| 体积    | (dV)   | (dxdydz)                                     |
| 柱坐标体积 | (dV)   | $(r,dr,d\theta,dz)$                          |
| 球坐标体积 | (dV)   | $(\rho^2\sin\varphi,d\rho,d\varphi,d\theta)$ |
| 曲面面积  | (dS)   | $(\sqrt{1+f_x^2+f_y^2},dxdy)$                |


你会发现一个很有用的规律：**真正需要死记的只有三个“带修正因子”的微元**——

- 极坐标面积：多一个 r；
- 柱坐标体积：多一个 r；
- 球坐标体积：多一个 $ρ^2sin⁡φ$；
- 曲面面积：多一个 $\sqrt{1+f^2_x+f^2_y}$​​。
