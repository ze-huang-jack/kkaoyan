
# 零、一些理解



一个图有n个结点，若边数少于n-1条，则此图必然是非连通的
一个图有n个顶点，那么最少需要n-1个边，才是连通的，但并不是有n-1条边就是一定连通的

一个图有n个顶点，那么最少需要n-1个边
这样的图叫生成树，用最少的边保持连通
对于生成树，若移除任何一条边，都会变成非连通图；
若添加任何一条边，则会形成一个回路


一个图有n个顶点，最少需要n个边，形成环路（环）

一个图有n个结点，若有大于n-1条边，则此图一定有环





n个结点，最多可以形成 $1+2+3+\dots+n-1$ 条边，即$\frac{n(n-1)}{2},\, n\geq 2$
换句话说，$\frac{n(n-1)}{2}$条边最少可以有 n 个结点


## 子图
设有两个图$G=(V,E),\, G'=(V',E')$，若$V' \subseteq V,\,\,E'\subseteq E$，且$E'$中每条边的两个端点都必须属于$V'$，则 $G'$ 是 $G$ 的子图
