## (十四)
【2011 统考真题】
21.已知循环队列存储在一维数组 $A[0\dots n-1]$ 中，且队列非空时 $front$ 和 $rear$ 分别指向队首元素和队尾元素。若初始时队列为空，且要求第一个进入队列的元素存储在 $A[0]$ 处，则初始时 $front$ 和 $rear$的值分别是（）。
A. $0,\ 0$
B. $0,\ n-1$
C. $n-1,\ 0$
D. $n-1,\ n-1$

选B，我误选了A
要搞清楚入队逻辑：
```c
rear=(rear+1) % n
```
题目要求第一个入队的元素在A\[0\]处，所以：
```c
(rear_初始 + 1) % n = 0
```
所以 rear_初始=n-1
