## (二)
![[Pasted image 20260905203224.png]]


top作为右值时代表栈顶结点本身
top作为左值代表top指针的指向

比如
```c
top=x
```
代表top指针指向x结点，即x成为新的栈顶结点

```c
x->next=top
```
代表x指向旧栈顶结点
