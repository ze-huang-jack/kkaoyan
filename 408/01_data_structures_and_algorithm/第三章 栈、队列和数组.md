# 二、一些理解
使用栈可以模拟递归的过程，以此来消除递归，但对于单向递归和尾递归而言，可以用**迭代**
的方式来消除递归

## 中缀表达式怎么变成后缀表达式
从左到右扫描中缀表达式：

1. **扫描到操作数（数字/字母）**  
    → 直接加入后缀表达式。
    
2. **扫描到 `(`**  
    → 直接入运算符栈。
    
3. **扫描到 `)`**  
    → 依次弹出栈顶运算符并加入后缀表达式，直到遇到 `(`；  
    → 将 `(` 弹出，但**不加入**后缀表达式。
    
4. **扫描到运算符 `+ - * /`**  
    → 若栈顶是 `(`，直接入栈；  
    → 若栈顶运算符的优先级 **≥** 当前运算符，弹出栈顶并加入后缀表达式，继续比较；  
    → 若栈顶优先级 **<** 当前运算符，当前运算符直接入栈。
    
5. **扫描结束**  
    → 将栈中剩余的所有运算符依次弹出，加入后缀表达式。
