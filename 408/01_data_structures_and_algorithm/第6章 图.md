
# 零、一些理解


一个图有n个结点，若边数少于n-1条，则此图必然是非连通的
一个图有n个顶点，那么最少需要n-1个边，才是连通的，但并不是有n-1条边就是一定连通的

一个图有n个顶点，那么最少需要n-1个边
这样的图叫生成树，用最少的边保持连通
对于生成树，若移除任何一条边，都会变成非连通图；
若添加任何一条边，则会形成一个回路


一个图有n个顶点，最少需要n个边，形成环路（环）

一个图有n个结点，若有大于n-1条边，则此图一定有环


n个结点，最多可以形成 $1+2+3+\dots+n-1$ 条边，即$\frac{n(n-1)}{2},\, n\geq 2$
换句话说，$\frac{n(n-1)}{2}$条边最少可以有 n 个结点


## 子图
设有两个图$G=(V,E),\, G'=(V',E')$，若$V' \subseteq V,\,\,E'\subseteq E$，且$E'$中每条边的两个端点都必须属于$V'$，则 $G'$ 是 $G$ 的子图

## 完全图
n个结点构成完全图，有 n(n-1)/2 条边
n个结点，能连的线都连了，形成的就是完全图

## 邻接矩阵

一个n x n 的邻接矩阵，非零元素（边）有m个，若是有向图，则有m条弧；若是无向图，则有2m条边



图的路径计数：$A^k[i][j]$代表从i到j长度为k的路径数量


广度优先遍历可以解决**无权图或权值相等**的单源最短路径问题

## (十二)
![[Pasted image 20260911214900.png]]

有向图**邻接表**构造规则：

- 每个顶点有一个**边表（出边表）**，保存**从该顶点出发**能到达的邻接点。
- 边表里存放的是**终点**。

> 例：有一条边 $u \to v$ 在顶点 $u$ 的边表里面，会写下顶点 $v$。 也就是：**$v$ 出现在 $u$ 的边表中**。

区分几个概念
- **出度**：顶点 $v$ 自己的边表里面有多少个结点（从v出发的边数），对应选项B。
- **入度**：$v$ 在其他顶点的边表里出现的总次数，对应选项C ✅
- **顶点v的度 / 依附于顶点v的边数**：入度+出度，对应A、D。

极大连通子图是**无向图**（不一定连通）的连通分量，极小连通子图是**连通无向图**的生成树
