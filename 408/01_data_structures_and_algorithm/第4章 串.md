# 一、一些理解
KMP 算法
next数组本质是找子串中 最长相同前后缀的长度

右滑位数=已匹配字符数 - 最后一个匹配字符的部分匹配值


$next[j]$ = $j$ 前面这一段$P[1]\sim P[j-1]$的最长相等前后缀长度 + 1
（如果串的下标从0开始，则直接右移即可，不用+1，且$next[1]=-1$）

规定$next[1]=0$

nextval 跟 next 数组的区别是，当 $p_{next[j]}=p_{j}$ 时，要继续找 $k=next[next[j]]$直到$p_{k}≠p_{j}$或者p=0为止

kmp会考比较次数、i和j的位置、右滑距离（右滑距离$=j - next[j]$ ）
