## (十二) 循环链表删除结点
![[Pasted image 20260905155507.png]]



对于26. Ans: A 
**循环单链表删除结点必须要找到被删结点的前驱结点**，将其next域改变。想要删除首元结点，首元结点的前驱要么是尾结点，要么是头结点（如果有的话）

对于27.  D
想要判断一个带头结点的循环单链表是否为空：
```c
head->next==head 
```
对于一个空循环单链表来讲：
```c
自然有
head->next==head;
推理有
head->next->next==head->next
head->next右值就是head
所以
head->next->next=head
```
只有一个元素时：
```c
p=head->next
p->next==head
即
head->next->next=head
```

这个题我误选了C，因为我以为要把尾结点的next域指向h，但是这是不用的，因为尾节点始终指向h，变的只是h的next域，h本身不变

说白了，这道题也是在考察**循环单链表的删除结点只需要改变被删结点的前继元素的next域**

而且这道题要考虑链表只有一个元素的情况，这个时候尾节点就是被删结点，需要将尾指针更新到头结点的位置，不然就会出现空指针

# 二、一些理解

首元结点是第一个存数据的结点，不是头结点

线性表长度 = 存data的结点个数
不算头结点

对于链表的next:
p->next左值表示p结点的next域
p->next右值表示p的后继结点

head本身就是头结点，rear本身就是尾节点
head->next表示首元结点（如果链表带头结点的话）
## 带头结点的循环单链表的最后一个结点的next域指向的是头结点还是首元结点？
头结点

带头结点循环单链表
```c
rear(尾节点)->next=头结点
头结点->next=首元结点
```
不带头结点循环单链表
```c
尾节点->next=首元结点
```
