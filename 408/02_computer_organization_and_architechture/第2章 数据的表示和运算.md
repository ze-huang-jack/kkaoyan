# 数制与编码
### 定点数的四种表示法
##### 1. 原码(Sign-Magnitude)
规则：
- 符号位+绝对值
+5 = 0000 0101
-5 = 1000 0101
简单，但是加减法麻烦，而且零有两种编码

##### 2. 反码(One's Complement)
规则：
- 正数不变
- 负数 = 符号位不变，数值部分取反
+5 = 0000 0101
-5 = 1111 1010
0不唯一

##### 3. 补码(Two's complement)
规则：
- 正数不变
- 负数 = 反码 + 1
+5 = 0000 0101 
-5 = 1111 1011
0唯一


原码变补码：
正数：原码 = 补码
负数：补码 = 符号位不变，数值部分取反后 + 1

**补码变原码**：全部取反后+1
例：
```
11110001 
先判断正负，这里是负数
取反-> 00001110
+1 -> 00001111 = 15  15是绝对值
负号 -15
```

已知 +10 的二进制，要得到 -10：取反 + 1
我们有+10，那么我们想得到-10的话，对于真数来讲，直接在前面改变符号就行
但是对于机器数来讲，+10在内存里是（按8位来算的话）0000 1010，但是机器数没有+-号，正负只能用0或1来表示，多个一个符号位，所以我们对0000 1010 取反 +1有：1111 0110 这个就是 -10

补码变真数：
正数：直接算
负数：取反+1，算绝对值，最后加上负号

##### 4. 移码
0唯一

##### 长类型转短类型：位截断
规则：
直接粗暴的截断


比如以下代码：
short si = -32767;
unsigned int ui = si;
那么ui = ?
解：
首先32767很接近32768, 也就是2^15, 那么32767就可以表示为15个1，0111 1111 1111 1111，那么-32767就是取反+1了，亦即1000 0000 0000 0001
那么有符号16bit转为无符号32bit，先符号扩展为
1111 1111 1111 1111 1000 0000 0000 0001
按照无符号来解释就是：
$2^{32} - 32767 = 2^{32} - (2^{15} - 1)$ 
=$2^{32} - 2^{15} + 1$

如果代码改成这样呢：
short si = -32767;
unsigned short ui = si;
ui = ?
解：
这里的区别是变成了有符号16bit转为无符号16bit，
那么不需要符号扩展，直接按无符号解释
1000 0000 0000 0001
亦即$2^{15} + 1$

# 运算方法和运算电路

### 补码加减运算的溢出判别方式
只有在**同号相加**或者**异号相减**的时候，才会发生溢出
例如：两个正数相加结果为负数，一个负数减去正数结果为正数
##### 1. 采用一位符号位
*只有两个符号相同的操作数相加才会发生溢出*
两个同号数相加，结果变成异号 → 溢出

##### 2. 采用一位符号位并结合进位情况
$C_f$  = Carry Flag = 符号位进位
$C_d$ = Carry digit/data = 数据位进位
当最高位数据位进位和符号位进位不一致时，会发生溢出

##### 3. 采用双符号位
变形补码：
采用双符号位，
若发生正溢出，则双符号位为01
若负溢出，则双符号位为10


### 逻辑移位和算数移位(Logical Shift and Arithmetic Shift)
逻辑移位：把数据当作无符号数处理
算数移位：把数据当做有符号数(**补码**)处理

逻辑左移：左边丢弃，右边补0
逻辑右移：右边丢弃，左边补0
永远补0，不考虑正负号

算数左移：左边丢弃，右边补0
**算数右移**：右边丢弃，左边补符号位

逻辑左移时，若高位移出的是1，则发生溢出
算数左移时，若移出的高位不同于移位后的符号位(算数左移前后的符号位不同)，则发生溢出
逻辑右移和算数右移不会发生溢出 (因为右移相当于除以2，数变得越来小，当然不会超出计算机表示的范围)

### 各类标志位的含义
OF：溢出标志，用于有符号数的加减运算的溢出判断
CF：进位/借位标志，用于无符号数的加减运算的溢出判断
SF：符号标志，用于指示有符号数加法运算的结果的正负性
ZF：零标志

如果溢出了，SF 就不可靠, 要靠OF中和一下
SF $\oplus$ 0 = SF 

#### 有符号数大小的比较
if OF xor SF = 0, then A > B
if OF xor SF = 1, then A < B
ZF = 1, A = B
#### 无符号数大小的比较
CF = 1, A < B
CF = 0, A > B
ZF = 1, A = B

### 加减运算电路
sub = carry in(低位的进位输入)
sub = 1时，为减法，低位进位输入为1， 且 输入位Y为Y的取反，加法器执行X+Ybar + 1
sub = 0时，为加法，低位进位输入为0，加法器执行 X + Y


# 浮点数的表示与运算

浮点数表示为：
$N=(-1)^{S} \times M\times R^E$
其中, S取0或1决定浮点数的符号：0的时候是正数，1的时候是负数
M是一个非负的定点小数，又叫尾数，用原码表示
E是一个定点整数，称为阶码（或指数），用偏置表示
R是基数（通常为2、4或16）
浮点数有符号、尾数和阶码组成
